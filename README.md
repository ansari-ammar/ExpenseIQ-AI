# ExpenseIQ AI

## AI-Based Personal Expense Prediction System Using Machine Learning

ExpenseIQ AI is an academic machine learning project designed to analyse historical financial transactions and generate experimental monthly expense predictions through an interactive Streamlit dashboard.

## Features

- Monthly expense prediction
- Estimated savings calculation
- Historical spending analysis
- Category-wise expense visualization
- Correlation analysis
- Machine learning model comparison
- Model performance evaluation
- Interactive dataset explorer

## Technologies Used

Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Plotly, Streamlit and Joblib.

## Dataset

Personal Finance Dataset from Kaggle.

## Run Locally

Install the required dependencies:

`pip install -r requirements.txt`

Launch the application:

`streamlit run app.py`

## Limitations

This project is an educational prototype. Model predictions have limited demonstrated reliability and should not be treated as dependable financial forecasts.
